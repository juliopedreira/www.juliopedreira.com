# My Personal site

## Serving site locally

Install mkdocs-material in a virtual environment:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install mkdocs-material
```

To serve it in [http://127.0.0.1:8000]()
```bash
source .venv/bin/activate
mkdocs serve
```
